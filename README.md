# Dev Digest AI marketplace

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugins/create-marketplace) with plugins for code review and spec-driven engineering.

Browse and search it at **<https://kosyakovr.github.io/dev-digest-ai-marketplace/>**.

## Install

```bash
# Add the marketplace once
claude plugin marketplace add kosyakovr/dev-digest-ai-marketplace

# Install a plugin
claude plugin install review-pack@dev-digest-ai
```

Inside a session, `/plugin` opens the same flow interactively.

Auto-update is off by default for third-party marketplaces. Turn it on in `/plugin` → **Marketplaces**, or run `claude plugin marketplace update dev-digest-ai` to pull changes manually.

## Use in a team repository

Commit this to the project's `.claude/settings.json` so that everyone who trusts the folder gets the marketplace and the plugins:

```json
{
  "extraKnownMarketplaces": {
    "dev-digest-ai": {
      "source": { "source": "github", "repo": "kosyakovr/dev-digest-ai-marketplace" }
    }
  },
  "enabledPlugins": {
    "review-pack@dev-digest-ai": true,
    "sdd-engineering@dev-digest-ai": true
  }
}
```

## Repository layout

```
.claude-plugin/marketplace.json   catalog: one entry per plugin
plugins/<name>/
  .claude-plugin/plugin.json      manifest; the only place the version lives
  skills/<skill>/SKILL.md         skills (plus references/, templates/)
  agents/<agent>.md               subagents
  README.md  CHANGELOG.md  LICENSE
scripts/                          CI checks and the README catalog generator
site/                             catalog website (React + Vite), deployed to GitHub Pages
docs/specs/                       specifications
.github/workflows/                validate on every PR, tag releases and deploy the site on main
```

## Development

```bash
python3 scripts/check_marketplace.py          # repository policy checks
python3 scripts/generate_catalog.py           # refresh the table above
claude plugin validate . --strict             # official validator: marketplace
claude plugin validate plugins/review-pack --strict

# Try a plugin without installing it
claude --plugin-dir ./plugins/review-pack

# Run the catalog site locally
cd site && npm install && npm run dev
```
